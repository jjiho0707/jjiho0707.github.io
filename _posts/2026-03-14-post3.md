## problem
There are N ramen factories around the house of Kyojun, a ramen enthusiast. Each factory is numbered sequentially from 1 to N. Kyojun wants to purchase exactly Ai ramen from factory i (1 ≤ i ≤ N). Kyojun can purchase ramen in the following three ways:
- Purchase one ramen from factory i (1 ≤ i ≤ N). In this case, the cost is B won.
- Purchase one ramen each from factory i and factory (i1) (1 ≤ i ≤ N-1). In this case, the cost is (B C).
- Purchase one ramen each from factory i, factory (i1), and factory (i2) (1 ≤ i ≤ N-2). In this case, the cost is (B 2C).
Write a program that outputs the amount Kyojun needs to purchase ramen at the minimum cost.

## input 
The first line contains a natural number N representing the number of ramen factories and two natural numbers B and C separated by a space. The second line contains N integers A1, ···, AN separated by spaces.

## output
print the minimum cost on the first line.

## range
3<=n<=10^6
1<=B,C<=10^6
0<=A_i<=10^6
