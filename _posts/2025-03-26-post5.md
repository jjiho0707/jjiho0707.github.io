the exchange argument consists of three part:
first : define what solution is. It can be a set, or array of some mathematical object, etc.

second : find a method to reduce the difference between X* and X.

denote optimal solution as $X^*$ and greedy algorithm's solution $X$.
and sort this arrays by following rule:
if i<j OP_n(i) is lower then OP_m(j)
if i and j is same, then push OP_2(i) first as long as A_i>0 and A_i+1 > A_i+2 holds
and later, fill OP_3(i) OP_2(i) OP_1(i) as much as possible by this order.
(intuitively, this is same as the order of greedy solution. and we do this to get more robust comparing X to X*, this is motivation.)




second: finding a method to reduce differene.
there exists first mismatch point. (if not, this is already proved. lol)
